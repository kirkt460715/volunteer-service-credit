# 活动志愿服务互认资料

该项目保存多个活动点的志愿服务、岗位覆盖和培训优惠记录。`data/credits.json` 是一组匿名合成资料，班段记录可注明共享服务，培训资格记录其使用情况及互认期间。

`data/service-periods.json` 提供按日的岗位需求、重叠履职、实际交接、更正和抵用流水。共享班的比例仅在经多方确认的同时履职区间使用。协议结束日期含当日，已消费额度的修订差额结转到下一次报名。两期现场抽查记录单列，抽中的班段也可能未取得实际人数。一次报名以相同的 `application` 串起各组织抵用记录，各组织使用各自协议。

要求 Python 3.11 或更新版本。运行基线检查可使用 `python3 -m unittest discover -s tests`。`src/records.py` 提供基础 JSON 资料读取能力。
